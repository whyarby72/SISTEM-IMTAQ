# TASK CONTEXT — IMP-S1-005

## Outcome

Implement Shared Platform RBAC catalogs and effective user-role assignments with explicit data-scope context.

## Scope

Roles and permissions are catalogs. User-role assignments are effective-dated and carry scope context. The `users` table must not gain a role string.

### Allowed now

- `roles`, `permissions`, `role_permissions`, and `user_role_assignments` migration;
- Shared Platform RBAC models and User relationships;
- effective-assignment query scope and schema/relationship tests;
- local PostgreSQL verification and task/change records.

### Not allowed now

- default institutional role assignment or management policy;
- login/SSO, password changes, Guardian/Staff account links;
- domain-specific scope resolvers or business transaction authorization;
- append-only audit/correction workflow;
- provider, staging or production implementation.
