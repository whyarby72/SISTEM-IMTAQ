# TASK CONTEXT — IMP-S0-001

## Outcome
Create a runnable Laravel/PostgreSQL-ready shared application foundation in `application/web/` with a test harness and safe environment/secret baseline.

## Scope
This is platform foundation only. It must be compatible with Shared Core + multiple future domain modules, while Academic remains the first delivered domain.

### Allowed now
- initialize Laravel application under `application/web/`;
- establish local environment example/configuration without real secrets;
- PostgreSQL connection baseline/config placeholders;
- baseline test command/harness;
- foundation README/run instructions where needed;
- repository-safe ignore rules if required.

### Not allowed now
- Student/Staff/Guardian business tables;
- Academic class/schedule/attendance/grade/report features;
- Google/Gmail SSO;
- OpenAI/AI integration;
- WhatsApp/Communication provider integration;
- Parent Portal;
- biometric/fingerprint;
- Tahfizh/Kesantrian/other future-domain implementation;
- framework-wide refactor unrelated to initialization.

## Foundation invariants
- one Laravel app, one PostgreSQL target, modular-monolith direction;
- no Academic-only application identity or duplicate future module foundation;
- no real API keys/passwords committed;
- generated `.env` is local/untracked; `.env.example` contains placeholders only;
- do not invent business policy or schema;
- use current stable dependency versions compatible with the chosen project environment; record exact installed versions;
- if network/package installation is blocked, report the technical blocker instead of fabricating completion.

## Safe-change baseline for this task
- Minimum Necessary Change;
- do not overwrite an existing `application/web/` application without inspecting it first;
- do not run destructive DB commands;
- no staging/production operation in this task;
- preserve Git history if the workspace is already a repository.

## Atomic checkpoint strategy
Recommended first atomic result: inspect environment + verify target path + initialize the application scaffold only if safe, then run the smallest verification that proves the scaffold is coherent.

Do not chain immediately into database migrations or later Sprint 0 tasks. Stop at the checkpoint and offer the owner timed choices.

## Read-on-trigger only
- Need detailed build convention → targeted section of `docs/07_implementation/CODEX_BUILD_INSTRUCTIONS.md`.
- Need non-trivial repository/protected-zone decision → `docs/07_implementation/CODEX_CHANGE_MANAGEMENT_AND_SAFE_MAINTENANCE.md`.

## Completion evidence
At full task completion, show:
- Laravel/version and dependency baseline;
- PostgreSQL-ready environment configuration without secrets;
- test command and result;
- files/areas changed;
- Change Manifest if non-trivial;
