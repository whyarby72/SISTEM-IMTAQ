# Task Context — IMP-S4-005

## Goal
Implement audited cancellation for future class sessions without deleting historical facts.

## Required authority
- `docs/02_architecture/POSTGRESQL_SCHEMA.md`
- `docs/02_architecture/SCHEDULE_CONFLICT_AND_CONSTRAINT_ENGINE.md`

## Allowed scope
- Add a transactional `CancellationService` using existing schedule-change and class-session structures.
- Mark eligible future sessions `CANCELLED`, record an applied cancellation change, and preserve the session row.

## Not allowed
- No attendance, period lock, communication announcement, or destructive session deletion.
- No cancellation of completed/past sessions and no production data changes.

## Verification
Run targeted cancellation tests, full Laravel suite, Composer validation, project structure and foundation checks. No migration is expected.

## Stop triggers
Stop before implementing attendance, communication, or period-lock workflows.
