# Briefing Workflow Pilot — IMP-S12-006

Status: siap disampaikan; belum dianggap diterima sebelum Azhar dan Wawan SN mengonfirmasi.

## Peran

- Azhar / Wali Kelas: mengisi attendance guru dan siswa, menambahkan catatan, lalu menyatakan data sudah benar.
- Wawan SN / Waka Akademik: memeriksa hasil pilot dan menangani koreksi setelah lock bila diperlukan.
- Super Admin: tetap memiliki akses edit penuh kapan pun.

## Alur singkat

1. Masuk sebagai Wali Kelas dan buka sesi kelas 3A atau 3B.
2. Periksa daftar siswa dan sesi yang tersedia.
3. Input status siswa per sesi: hadir, tidak hadir, atau izin; catatan dapat ditambahkan.
4. Input attendance guru dilakukan oleh Wali Kelas; guru tidak melakukan self-confirm.
5. Simpan/finalisasi data sesi. Data tetap editable sesuai hak akses.
6. Waka Akademik memeriksa hasil dan mencatat defect bila ada.

## Batasan pilot

- Data yang dipakai adalah sample pilot kelas 3A/3B periode 4–12 September 2026.
- Jangan menghapus fakta historis; koreksi dilakukan melalui jalur koreksi/audit.
- Catat setiap masalah pada defect log pilot.
