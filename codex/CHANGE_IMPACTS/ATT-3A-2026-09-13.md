# ATT-3A — Hero Session Header

## Scope

Presentation-only refinement of the Attendance Session hero header. The roster, action bar, teacher workflow, summary, routes, forms, and attendance semantics are unchanged.

## Impact

- Reorganized existing session metadata into a responsive hero metadata grid.
- Clarified the class/subject identity, date/time, scheduled teacher, recorder, and session status.
- Replaced the user-facing label `Diabsen oleh` with `Dicatat oleh`.
- Added human-readable session status labels, including `Dijadwal ulang`.
- Added scoped responsive styling for desktop, tablet, and mobile layouts.

## Safety

- No controller, service, model, route, migration, database, RBAC, or business-rule changes.
- No new icon dependency or asset.
- No database write or real-data change.
