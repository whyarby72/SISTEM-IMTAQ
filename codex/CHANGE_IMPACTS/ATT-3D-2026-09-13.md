# ATT-3D — Attendance Roster Toolbar & Client-Side Search

## Scope

Presentation and client-side filtering only for the `Kehadiran santri` roster toolbar.

## Impact

- Added compact `Cari santri` search with placeholder `Cari nama santri...`.
- Search is case-insensitive, trims whitespace, and supports partial name matching.
- Matching uses stable `data-student-row` and `data-student-name` attributes.
- Non-matching rows use the visual `hidden` attribute only; rows and all form inputs remain in the DOM and submission scope.
- Added a compact `Tidak ada santri yang cocok.` empty state without destructive DOM removal.
- Existing `Tandai semua hadir` behavior and roster order remain unchanged.

## Safety

- No controller, service, model, route, migration, database, RBAC, or business-rule changes.
- No AJAX, API, server query, pagination, sorting, or status filter.
