# ATT-3F — Modern Attendance Action Footer

## Scope

Presentation-only refinement of the existing sticky Attendance Session action footer.

## Impact

- Added a compact CSS progress ring showing the existing live filled/total percentage.
- Preserved the existing filled count, missing count, readiness text, teacher blocker, and live update behavior.
- Kept `Simpan draf` as the secondary action and `Sahkan kehadiran` as the primary action with truthful disabled and `aria-disabled` semantics.
- Refined footer surface, spacing, natural-width actions, and mobile stacking while preserving sticky behavior.
- Completed/read-only sessions still do not receive editable footer actions.

## Safety

- No finalizer, teacher gate, student completeness logic, form action/method, route, controller, service, database, RBAC, or business-rule changes.
- No database write or real-data change.
