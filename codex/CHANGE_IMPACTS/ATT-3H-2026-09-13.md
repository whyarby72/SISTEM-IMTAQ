# ATT-3H — Top Attendance Action Cluster

## Scope

Presentation and safe form orchestration for the top action cluster above the student roster.

## Impact

- Added top actions for `Tandai semua hadir`, existing client-side search, `Simpan draf`, and `Sahkan kehadiran`.
- Top save/finalize buttons reference the existing `attendance-form` and the exact existing finalize route/method.
- Existing readiness function now updates all finalize buttons together; no second readiness algorithm was introduced.
- Sticky footer remains the canonical progress/readiness/safety control and is not duplicated above.
- Responsive layout keeps bulk feedback left and utility actions right on desktop, wraps on tablet, and stacks safely on mobile.

## Safety

- Bulk action and search semantics unchanged; no input is removed, disabled, or rewritten.
- No controller, service, model, route, migration, database, RBAC, or business-rule changes.
