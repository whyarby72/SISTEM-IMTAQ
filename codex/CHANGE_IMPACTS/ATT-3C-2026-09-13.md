# ATT-3C — Modern Teacher Attendance Card

## Scope

Presentation-only refinement of the `Rekap kehadiran guru` section on the Attendance Session page.

## Impact

- Editable teacher participation rows now use identity, initials avatar, role badge, status control, note control, and compact save action in a responsive operational grid.
- Multiple teacher participations remain separate and distinguish `Guru utama` from `Guru pengganti`.
- Completed/read-only sessions now show a compact teacher summary without editable controls.
- Existing controlled status vocabulary, null display (`Belum dicatat`), values, old input behavior, field names, route, and submission semantics are preserved.

## Safety

- No controller, service, model, route, migration, database, RBAC, or business-rule changes.
- No new icon dependency, image upload, query, or avatar data field.
- No database write or real-data change.
