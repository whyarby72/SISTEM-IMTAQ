# ATT-3B — Modern Attendance KPI Summary Tiles

## Scope

Presentation-only refinement of the eight server-rendered attendance summary tiles beneath the Attendance Session hero.

## Preserved

- Transaction/session summary buckets and reconciliation: Total, Hadir, Terlambat, Sakit, Izin, Dikecualikan, Tidak hadir, and Belum diisi.
- All count calculations, zero values, live behavior elsewhere, teacher workflow, roster, action bar, routes, and backend logic.

## Impact

- Added compact decorative accents with `aria-hidden` so text remains the meaning carrier.
- Added restrained per-status accent palette without changing severity or scoring semantics.
- Added responsive grid: eight columns when space permits, four columns on tablet, and two columns on mobile.
- Added a neutral, slightly stronger pending treatment only when `Belum diisi` is greater than zero.

## Safety

- No controller, service, model, route, migration, database, RBAC, or business-rule changes.
- No new icon package or asset.
- No database write or real-data change.
