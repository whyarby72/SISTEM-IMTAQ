# Change Impact — IMP-SCH-001

## Scope

Mengaktifkan recurrence `WEEK_OF_MONTH` pada jalur admin schedule existing agar aturan v1.1 seperti `WEEK_OF_MONTH_IN(2,4,5)` dapat disimpan dan digenerate.

Checkpoint lanjutan juga menambahkan seeder idempotent untuk master guru dan mata pelajaran Akademik dari crosswalk v1.1 yang telah disetujui. Olahraga sengaja tidak di-seed.

Struktur resmi Tahun Ajaran 2026/2027 juga dibuat terpisah dari struktur pilot, menggunakan organisasi `IMTAQ-ISY-KARIMA` / `IMTAQ ISY KARIMA`, Semester 1, tingkat 1–3, dan lima kelas resmi.

Planner import read-only juga ditambahkan. Planner memetakan teaching group ke ID kelas resmi, mengecualikan olahraga, dan belum menulis teaching assignment, schedule rule, session, atau attendance.

Fondasi kelas gabungan ditambahkan melalui `schedule_rule_groups`, sehingga satu schedule rule dapat memiliki lebih dari satu scope kelas. Tabel masih kosong; integrasi generator/session gabungan belum dipromosikan.

Integrasi tahap berikutnya menambahkan `class_session_groups`. Generator kini membuat satu session per aktivitas/tanggal dan menyimpan beberapa scope kelas; snapshot peserta membaca enrollment dari seluruh scope tersebut. Teacher participation tetap satu per session.

Importer v1.1 kini sudah dijalankan ke periode resmi dalam status `DRAFT`: 51 rule, 65 scope kelas, 3 calendar exception. Session dan attendance belum dibuat.

Generation tahap berikutnya selesai: 1.261 official `class_sessions`, 1.570 session scopes, termasuk 309 joint sessions untuk `TG-B`. Tiga tanggal pembatalan tidak menghasilkan session. Rerun menghasilkan total tetap 1.261 (idempotent).

QA bundle terarah selesai: 20 tests passed, 74 assertions. QA cases 16, 17, dan 19 masih partial karena publish enforcement dan revision audit khusus importer belum selesai.

Gap QA 16, 17, dan 19 kemudian ditutup: validator publish menolak identity/scope invalid, importer menaikkan version, dan reconciliation menulis audit revision untuk 51 assignment serta 51 rule.

Workflow publikasi sekarang tersedia melalui service dan endpoint admin dengan alur `DRAFT -> VALIDATED -> PUBLISHED`. Validasi memeriksa guru, mata pelajaran, dan scope kelas sebelum transisi; setiap transisi assignment dan rule dicatat ke audit log. Tombol validasi dan publikasi tersedia pada halaman jadwal resmi dengan RBAC admin akademik/super admin yang existing. 51 rule dan 51 assignment resmi sudah divalidasi dan diterbitkan.

## Expected impact

- Schedule admin dapat memilih minggu ke-1 sampai ke-5.
- `ClassSessionGenerator` existing tetap menjadi sumber pembuatan session.
- Tidak membuat attendance transaction.
- Tidak mengubah database schema, RBAC, atau business semantics attendance.
- Seeder master tidak membuat schedule rule atau class session.
- Struktur resmi tidak memindahkan, mengubah, atau menghapus histori pilot.
- Migration baru hanya membuat `schedule_rule_groups`; schedule rule, class session, dan attendance existing tetap utuh.
- Migration session scope hanya menambah `class_session_groups`; data existing tetap utuh.
- Import schedule tidak membuat attendance transaction.
- Attendance existing tetap 20; teacher participation official belum dibuat oleh schedule generation.

## Explicitly unchanged

- Olahraga tetap di luar modul Akademik.
- Import teacher schedule v1.1 belum dijalankan.
- Kelas gabungan `TG-B` belum dipromosikan ke production.
- Source crosswalk sudah dipakai importer; lifecycle publish sudah diimplementasikan dan dijalankan pada data resmi.

## Validation

Targeted schedule admin dan generator tests passed: 9 tests, 33 assertions.
