# ATT-3E — Modern Roster Styling Alignment

## Scope

Presentation-only refinement of the student attendance roster.

## Impact

- Student names remain source-rendered without case conversion or title-casing; no stored data is changed.
- Workflow badges remain visible and are compacted visually.
- Roster headers and mobile labels use concise `Santri`, `Status`, `Catatan`, and `Ketertiban` wording.
- Native attendance selects and progressive-disclosure actions receive consistent sizing, spacing, focus, and hover treatment.
- Rows use lighter dividers and subtle hover/focus-within surfaces while preserving the existing responsive card transformation.
- Search toolbar and client-side filtering remain unchanged.

## Safety

- No numbering or row menu added.
- No controller, service, route, migration, database, RBAC, or business-rule changes.
- No input names, status values, grooming semantics, ordering, or bulk action changes.
