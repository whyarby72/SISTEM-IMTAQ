# Change Manifest — JOINT-1C — Scope-Aware Joint Class Conflict Integrity

## Conflict path inventory

- `ScheduleRuleConflictChecker`: SCHEDULE_RULE_LEVEL; now compares effective candidate scope with effective existing rule scope.
- `RescheduleService`: CLASS_SESSION_LEVEL; now compares source session scope with target session scope, including legacy no-group fallback.
- `ExtraSessionCreator`: CLASS_SESSION_LEVEL; remains a single-class input contract, but detects overlap with any existing session scope containing that class.
- `ScheduleRuleRevisionService`: CLASS_SESSION_LEVEL generation guard; revised rule scope is used for occupancy checks.
- `ClassSessionGenerator`: no class-overlap validation existed; teacher conflict and joint-session grain unchanged.
- `SwapService`: TEACHER_ONLY; no class-overlap validation, unchanged.
- `TeacherScheduleImporter`: mapping/import path; creates joint groups and was not changed.

## Changed

- `application/web/app/Domains/Academic/Services/AcademicClassScopeResolver.php`
  - Centralizes effective class IDs for schedule rules, candidates, and sessions, plus legacy session fallback query constraints.
- `application/web/app/Domains/Academic/Services/ScheduleRuleConflictChecker.php`
  - Detects class conflicts on any intersecting effective scope.
- `application/web/app/Domains/Academic/Services/RescheduleService.php`
  - Protects all source session scope classes during replacement conflict validation while preserving JOINT-1A group copying.
- `application/web/app/Domains/Academic/Services/ExtraSessionCreator.php`
  - Prevents a single-class extra session from overlapping a joint session containing that class.
- `application/web/app/Domains/Academic/Services/ScheduleRuleRevisionService.php`
  - Uses revised rule effective scope for generated-session occupancy checks.
- `application/web/tests/Feature/Academic/JointClassConflictIntegrityTest.php`
  - Covers joint/secondary overlap and disjoint scope behavior.
- `application/web/tests/Feature/Academic/RescheduleServiceTest.php`
  - Covers secondary-scope conflict rejection.

## Unchanged contracts

- Temporal overlap boundaries, weekday/recurrence/effective-date semantics, teacher conflict and lock order, anchor policy, one-session-per-joint-event grain, importer mapping, routes, RBAC, database schema, participants, attendance facts, and historical records.

## Known gaps and governance

- `DB_HARDENING_GAP`: the current PostgreSQL exclusion constraint protects `ClassSession.class_id`, not secondary `scopeGroups`.
- `CONCURRENCY_GAP`: application checks use the existing transaction/teacher lock strategy; real PostgreSQL contention protection for secondary scope classes remains unverified and is not claimed race-proof.
- Extra/ad-hoc session input remains single-class; no input-contract redesign was made.
- Migration, seed, import, reconciliation, and real database writes: NONE.
- Deferred known risk: database hardening/concurrency verification for secondary joint scope.
