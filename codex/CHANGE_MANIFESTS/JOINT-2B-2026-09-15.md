  - Adds regressions for unfiltered, anchor-class, secondary-class, unrelated-class, bulk-preview, label, and canonical CTA behavior.

## Semantic rules

- Effective exception scope is `ClassSessionGroup.class_id` when scope groups exist, falling back to `ClassSession.class_id` for ordinary sessions.
- The queue is a distinct `ClassSession` collection: an unfiltered joint session appears once; either matching class filter includes that same session once; an unrelated class excludes it.
- Joint labels are derived from loaded scope class identities and shown as `Kelas A + Kelas B` with `Kelas gabungan`; single-class labels remain unchanged.
- Facet and result counts continue counting queue sessions, not scope rows or students.
- Bulk cancellation uses the same effective scope predicate and canonical session IDs; the existing Waka/Super Admin authorization and safeguards remain authoritative.
- Attendance detail, monthly reports, routes, backend business facts, database schema, seed/import, RBAC, and historical data are unchanged.
