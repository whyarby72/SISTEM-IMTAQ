# OpenAI Codex Usage Snapshot — 2026-09-02

**Volatile external reference. Re-check current OpenAI documentation/settings before changing subscriptions or model configuration.**

Current official OpenAI guidance used for v1.16 operating policy:
- Codex usage on supported ChatGPT plans is affected by model, task complexity, context, reasoning, speed, tools and where the task runs; large codebases/extended sessions consume more than small tasks.
- Codex/Work/related agentic features can draw from a shared agentic allowance/credit pool where available on the plan.
- Eligible Plus/Pro users may be able to add credits after included limits are reached; account UI shows available options/reset information.
- Current GPT-5.6 family guidance: Sol = flagship capability, Terra = intelligence/cost balance, Luna = cost-sensitive/high-volume.
- Current OpenAI model guidance recommends choosing reasoning effort intentionally rather than defaulting to the highest level.
