# Progress & Approval Guide

Progress is calculated from task queues/module registry, not from how many files Codex changed.

## Current baseline
- Current task: `IMP-S0-001`
- Academic planning: 100%
- Academic implementation: 0%
- System domain implementation: 0%
- Overall delivery: 6%

## A task may be approved as complete only when
- task deliverable exists;
- required tests/checks pass;
- no hidden policy activation occurred;
- task queue/status and WORK_LOG are updated;
- Change Manifest exists for non-trivial code work;
- PROJECT_PROGRESS.md was regenerated after task-state change.

## Numbered options
Codex ends with 3–4 choices. Option 1 must be the primary recommendation. Choosing `1` is safe only if the previous task really closed successfully and option 1 is an executable next step.
