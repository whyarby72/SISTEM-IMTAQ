# Which Prompt Should I Use?

- First time opening the bundle in Codex → `00_START/COPY_PASTE_FIRST_PROMPT.txt`
- Continue after a task → `01_PROMPTS/02_CONTINUE_NEXT_TASK.txt`
- New chat after interruption → `01_PROMPTS/03_RESUME_AFTER_INTERRUPTION.txt`
- I only want to know status → `01_PROMPTS/04_STATUS_ONLY_NO_CHANGES.txt`
- Something is broken → `01_PROMPTS/05_BUG_FIX.txt`
- I want a new behavior → `01_PROMPTS/06_FEATURE_OR_CHANGE_REQUEST.txt`
- I have decided a pending policy → `01_PROMPTS/07_POLICY_DECISION_INPUT.txt`
- Shared Student/Staff/RBAC contract must change → `01_PROMPTS/08_SHARED_CORE_OR_CROSS_MODULE_CHANGE.txt`
- Database structure must change → `01_PROMPTS/09_DATABASE_SCHEMA_CHANGE.txt`
- I want a test audit → `01_PROMPTS/10_TEST_AND_REGRESSION_AUDIT.txt`
- Prepare release for staging → `01_PROMPTS/11_PREPARE_STAGING_RELEASE.txt`
- A release is broken → `01_PROMPTS/12_ROLLBACK_OR_HOTFIX.txt`
- Codex forgot to close/update progress → `01_PROMPTS/13_CLOSE_TASK_AND_UPDATE_PROGRESS.txt`
- Start planning Tahfizh/Kesantrian/etc. → `01_PROMPTS/14_NEW_MODULE_PLANNING.txt`
- Explicitly start future OpenAI work → `01_PROMPTS/15_AI_FUTURE_WORK.txt`
- Explicitly start future WhatsApp/Communication work → `01_PROMPTS/16_COMMUNICATION_FUTURE_WORK.txt`
- Design only, no code → `01_PROMPTS/17_ARCHITECTURE_ONLY_NO_CODE.txt`
- UI change → `01_PROMPTS/18_UI_UX_CHANGE.txt`
