# Staging Release Checklist

- [ ] Exact Git revision/release candidate identified.
- [ ] Working tree/release state understood.
- [ ] Required tests pass.
- [ ] Migration list reviewed.
- [ ] Environment/config changes documented.
- [ ] Secrets not packaged in source.
- [ ] Persistent storage separated from release code.
- [ ] Backup/restore implications reviewed.
- [ ] Smoke-test scenarios documented.
- [ ] Rollback/feature-disable path documented.
- [ ] Change Manifest(s) linked to the release.
