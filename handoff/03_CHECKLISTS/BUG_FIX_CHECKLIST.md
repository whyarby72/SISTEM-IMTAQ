# Bug Fix Checklist

- [ ] Reproduction/evidence established.
- [ ] Expected behavior confirmed from authoritative contract.
- [ ] Owning module identified.
- [ ] Recent related change inspected if relevant.
- [ ] Minimum Necessary Change applied.
- [ ] Regression test added where practical.
- [ ] No unrelated refactor.
- [ ] Required tests pass.
- [ ] Change Manifest includes rollback/deploy implications.
