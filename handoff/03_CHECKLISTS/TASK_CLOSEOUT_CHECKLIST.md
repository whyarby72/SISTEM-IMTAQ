# Task Closeout Checklist

- [ ] Deliverable matches the task, not extra future work.
- [ ] Required automated tests pass.
- [ ] Structural validation passes where relevant.
- [ ] Impact/write scope did not silently expand.
- [ ] No old applied migration was edited.
- [ ] POLICY_PENDING/FUTURE behavior remains inactive unless explicitly authorized.
- [ ] Change Manifest completed for non-trivial code work.
- [ ] `codex/WORK_LOG.md` updated.
- [ ] Task queue status/progress updated.
- [ ] `NEXT_ACTION.md` updated if task closed.
- [ ] `python scripts/update_project_progress.py` run after progress change.
- [ ] User-facing progress comes from `PROJECT_PROGRESS.md`.
