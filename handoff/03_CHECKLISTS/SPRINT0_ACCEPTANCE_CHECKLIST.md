# Sprint 0 Acceptance Checklist

Use with `docs/07_implementation/IMPLEMENTATION_GATES.md`.

## IMP-S0-001
- [ ] Laravel application exists under `application/web/`.
- [ ] Application is runnable in the documented development setup.
- [ ] Test harness runs.
- [ ] PostgreSQL development configuration baseline exists.
- [ ] Timezone/environment baseline is documented.
- [ ] Secrets are excluded from Git.
- [ ] No Academic business feature was prematurely implemented.

## IMP-S0-002 / IMP-S0-003 gate
- [ ] Module boundaries/conventions established.
- [ ] Git/branch/change-ID conventions established.
- [ ] Protected zones and impact classes documented/enforced.
- [ ] Applied migration immutability rule established.
- [ ] Change Manifest workflow established.
- [ ] Repeatable verification commands exist.
- [ ] Development → staging → production target is documented.
- [ ] Rollback/feature-disable strategy exists.
- [ ] Gate A evidence is complete before Sprint 1.
