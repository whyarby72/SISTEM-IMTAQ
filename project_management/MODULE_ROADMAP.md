# SYSTEM MODULE ROADMAP

## Default recommended sequence

The user may reprioritize, but absent a new decision the default sequence is:

1. Shared Platform/Core foundation + Academic implementation/pilot.
2. Tahfizh planning → implementation.
3. Kesantrian / Adab & Kedisiplinan planning → implementation.
4. Ruhiyah / observable ibadah planning → implementation.
5. Kepengasuhan planning → implementation with stricter privacy.
6. Bahasa planning → implementation.
7. Kegiatan & Kompetensi planning → implementation.
8. Administratif & Layanan planning → implementation.
9. Cross-domain Student 360 / management / parent reporting.
10. Shared AI read assistant → draft assistant → controlled actions after stable validated data.

## Mandatory gate per new module

`G0 Governance/Scope → G1 Business Process/Grain → G2 Data Dictionary/Schema → G3 Ownership/RBAC/Lifecycle → G4 KPI/Reporting/DQ → G5 UAT/Migration/Handoff → IMPLEMENT → PILOT → ACTIVE`

No module may skip directly from idea to dashboard/AI.


## Shared Communication / WhatsApp future gate
Shared Communication now covers two future tracks: (1) Parent/Guardian published-artifact delivery and (2) institutional staff communication using `ANNOUNCEMENT`, `REMINDER`, and `ACTION_REQUEST`. Internal broadcast/reminder work depends on stable Staff/Organization/RBAC/queue foundations; teacher availability confirmation additionally depends on stable Academic schedule/session/teacher obligations and approved timing/escalation policy. Parent delivery still depends on Guardian/recipient and published-report foundations. This shared workstream is not part of the eight-domain progress denominator.

## Parent Portal future gate
After Shared Core Guardian + Shared Platform authentication/RBAC/audit and a stable published Academic parent artifact exist, implement Parent Portal as a read-only Guardian-facing pilot. Portal authorization must be proven before WhatsApp secure links are relied upon for report access. Parent Portal is a shared workstream and is excluded from the eight-domain progress denominator.
