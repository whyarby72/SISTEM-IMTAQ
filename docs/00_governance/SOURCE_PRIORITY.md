# Source Priority and Conflict Resolution

When two sources conflict, use this priority order unless an explicitly newer authorized decision supersedes it:

1. Official Yayasan / Idaroh decision.
2. Official IMTAQ leadership decision.
3. Approved SOP.
4. Latest approved Base Engine / approved amendment.
5. Latest canonical Data Dictionary / architecture contract in this workspace.
6. Application implementation.
7. Operational spreadsheet.
8. Informal notes/chat.

## Codex rule
If implementation conflicts with a higher-priority source, do not silently preserve the implementation. Record the conflict and request/perform an explicit correction according to authority.

The active P1–P13 specifications in `docs/` incorporate documented Academic amendments to the Base Engine. Historical snapshots in `archive/` are never active authority.
