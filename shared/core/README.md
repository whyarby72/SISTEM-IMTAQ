# Shared Core

Shared Core is the canonical identity/institutional-context foundation for every SISTEM IMTAQ domain.

**Authoritative design:** `docs/10_shared_core/`.

Owns canonical Student, Guardian, Staff, Organization, shared locations/period references and identity relationships. It integrates with Shared Platform authentication/RBAC/audit but does not absorb domain transactions.

Key rule: domains consume Core through explicit services/contracts and may not create duplicate Student/Staff/Guardian masters.
